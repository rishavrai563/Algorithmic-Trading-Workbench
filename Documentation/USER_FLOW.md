# User Flow

## Main flow

```text
Dashboard
   ↓
Strategy Builder
   ↓
Parameters
   ↓
Run Backtest
   ↓
Backtest Results
   ↓
Explore Parameters
   ↓
Compare Strategies
```

## Task 1: Create and backtest a strategy

### User goal
Create a strategy, configure it, run a backtest, and understand the result.

### Expected flow

1. Open Dashboard.
2. Open Strategy Builder.
3. Create the strategy rule.
4. Open Parameters.
5. Select strategy values and historical period.
6. Run the backtest.
7. Observe the running state.
8. Open Backtest Results.
9. Understand the performance and trades.

## Task 2: Explore parameters

### User goal
Change one or more parameters and understand what changed.

### Expected flow

1. Start from a completed backtest.
2. Open Explore Parameters.
3. Change one or more parameters.
4. Run a variation.
5. Open Compare Strategies.
6. Compare the original and changed runs.
7. Explain what changed.
